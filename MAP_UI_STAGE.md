# Переработка интерфейса — этап 1: карта и компактные меню

Этап реализован поверх `a723448`. Это первая часть запроса на обновление интерфейса, редактор меток и Warrior SVG Studio. Расширенный редактор и визуальная студия в эту сборку ещё не входят.

## Что работает

* Карта занимает всю рабочую область. Explorer не прикреплён к главному экрану постоянно: это отдельная нижняя выдвижная диалоговая панель по запросу.
* Слева снизу — компактные полупрозрачные кнопки **Карты**, **Слои**, **Метки**, **Инструменты**; справа — кнопки масштаба с областью нажатия 48 dp.
* Слева сверху — координаты центра/выбранной метки, уровень zoom и локальные метры на пиксель (не масштаб 1:N, требующий физических характеристик дисплея).
* Включаемая географическая сетка с адаптивным шагом, подписями и учётом перехода через ±180°. Настройка сохраняется.
* Меню **Метки**: Все метки (дерево Explorer), Метки на экране (включая вложенные папки, исключая скрытые слои), Новая метка, Поиск на карте, Опции. Поиск локальный: по названиям или координатам `широта, долгота`; запросов геокодирования нет.
* Карты позволяют включать онлайн OpenStreetMap или только существующий кэш. Полноценный менеджер офлайн-атласов пока отсутствует.
* Explorer: компактный файловый список / карточки с настоящими SVG-миниатюрами и координатами. На узком экране дерево вынесено в меню **Папки**, на широком остаётся боковым. Все операции перенесены в **Операции**; копирование, вырезание, вставка, удаление, папки, слои, сортировка и перетаскивание сохраняются. Сортировка и режим отображения не изменяют данные объектов.
* Значок и название постоянно отображаются на карте. Действия метки доступны нажатием на значок/подпись; повторное нажатие после закрытия всплывающего окна открывает базовые параметры. Полноценной карточки с описанием пока нет.
* Значки доступны через **Инструменты → Warrior Icons**, из параметров метки и через кнопку **Значки** в Explorer. Массовое назначение выбранным меткам сохранено.
* Положение карты восстанавливается при пересоздании Activity (например, повороте).

## Сохранность данных и безопасность

`ObjectStore`, `MapItem`, модуль `icons` и manifest не изменены относительно `a723448`. Версия SQLite остаётся 2; новая миграция не нужна. Код обновления не удаляет и не пересоздаёт базу или библиотеку SVG. `applicationId` остаётся `ru.warriorrus.app`; versionCode повышен с 3 до 4. Сертификат подписи соответствует опубликованному `downloads/Warrior-rus-2.0-icons-debug.apk`. Устанавливайте APK поверх этой сборки без удаления приложения и очистки данных. APK, собранный другим debug-ключом (например, в другом runner GitHub Actions), может быть несовместим по подписи: фактическое обновление надо проверить на устройстве.

Manifest сохраняет только INTERNET, нужный карте. GPS, определение местоположения, аналитика, телеметрия, автоматический экспорт и передача пользовательских объектов не добавлены. Поиск и сетка работают локально.

## Следующие этапы — пока не реализованы

1. Расширенный редактор меток: описание, дополнительные поля, локальные вложения, выбор значка/цвета до первого сохранения, полноценная подробная карточка, экспорт свойств в поддерживаемые форматы. Сейчас значок/цвет задаются существующим механизмом Warrior Icons после создания метки.
2. Warrior SVG Studio: рисование пальцем/стилусом, сглаживание, фигуры, трансформации, заливка/обводка, undo/redo, сохранение SVG с повторным визуальным редактированием в `Созданное от руки`. **SVG +** пока открывает сохранённый текстовый редактор Warrior Icons; визуальная студия не подменяется макетом.
3. Оценка и доработка взаимодействий на физическом телефоне. Интерфейс использует собственные компоненты и оформление, а не ресурсы или код AlpineQuest.

## Проверки и пределы проверки

Тесты Robolectric API 23 и 35 проверяют полноэкранную иерархию карты, пункты меню, открытие Explorer, создание папки через меню операций, переключение карточек, сетку, сохранение данных между запусками, актуальные маркеры и прежние функции Warrior Icons. Это тестовое хранилище; установка поверх приложения на реальном телефоне не выполнялась. Схема/код базы и библиотеки дополнительно сравниваются с `a723448`, сертификаты старого и нового APK сравниваются напрямую.

На устройстве нужны проверки: установка поверх существующей сборки без потери пользовательских данных; подписи и сетка при масштабировании; управление пальцем и размер панелей на конкретном дисплее; USB/MTP и доступ к media-каталогу. Создание SVG проверяется существующими тестами Warrior Icons; сохранение SVG из визуального редактора нельзя проверить, пока Studio не реализован.
