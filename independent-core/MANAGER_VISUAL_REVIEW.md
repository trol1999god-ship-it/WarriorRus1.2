# Менеджер: визуальная проверка 30 октября 2026

Это проверка читаемости и доступности отдельных экранов самостоятельного проекта,
не приёмка всей равноценности 26.1. Эталонных снимков менеджера в checkout нет.
99 локальных ресурсов в migration/workspace-assets.json сверены по SHA256 без
расхождений; это подтверждает сохранность графики/Arimo, но не размещение иконок.

## Наблюдения до исправления

Commit 24b3cd5, PR CI 41071853087. API23 job 124117964815 и API35 job
124117964509 собрали по 10 PNG. PNG получены через GitHub connector из журнала
CI; каждый base64-пayload декодирован с проверкой SHA256. Реальные PNG просмотрены.
Полные файлы находятся в обычных QA artifacts, локальная копия — вне Git,
/workspace/work/manager-visual/baseline-api23 и baseline-api35.

| Наблюдение | Подтверждение |
|---|---|
| Альбомная ориентация съедает список | На обеих API список отсутствует, на API35 нижняя кнопка обрезана; строка для открытия описания недоступна |
| Arimo не применяется | Фактические Typeface всех текстов главного портретного экрана отличаются от загруженного Arimo (0 из 14) |
| API35 IME закрывает диалог | landscape-name-ime показывает полноэкранный extract editor с DONE вместо кнопок диалога |
| Ночной режим не меняет тему менеджера | API23 nightMask=32, но PNG менеджера остаётся светлым; на API35 ночная клавиатура сочетается со светлым диалогом |

В сборщике также обнаружены две границы: один API35 night-portrait-main фактически
остался landscape (ориентация=2); у API23 landscape-name-ime флаг IME был true,
но на PNG клавиатуры нет. Эти кадры не засчитываются как нужное состояние.
Ожидание ориентации усилено проверкой реальных размеров/Configuration; IME теперь
проверяется по видимому accessibility-окну INPUT_METHOD, а не по строке в dumpsys.

## Правки по наблюдениям

- Шапка менеджера прокручивается и оставляет место списку/нижней кнопке на коротком экране.
- Arimo применяется с сохранением bold/italic в видимых виджетах и диалогах.
- Этот Activity выбирает стандартную Material light/dark тему по фактическому системному nightMode. Нового переключателя и выдуманной эталонной палитры нет.
- Поля менеджера запрещают fullscreen/extract IME; диалоги используют adjustResize, описание помещено в ScrollView.
- Инструментация прокручивает к невидимому элементу до нажатия, по-прежнему требует visible/enabled и принятый ACTION_CLICK.
- Визуальный сценарий теперь требует Arimo, видимого списка/нижней кнопки, реальной IME, полностью видимых Save/Cancel и инжектирует настоящее касание Cancel.

Новые Android-результаты и просмотр исправленных PNG будут добавлены после CI.
Точное расположение/состав согласованных иконок менеджера и полная визуальная
равноценность остаются непринятыми без эталонного сравнения. requirements.json и
release_gate.py не изменяются. Данные только синтетические, подпись одноразовая.
