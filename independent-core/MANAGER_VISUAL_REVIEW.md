## Правки по наблюдениям

- Шапка менеджера прокручивается и оставляет место списку/нижней кнопке на коротком экране.
- Arimo применяется с сохранением bold/italic в видимых виджетах и диалогах.
- Этот Activity выбирает стандартную Material light/dark тему по фактическому системному nightMode. Нового переключателя и выдуманной эталонной палитры нет.
- Поля менеджера запрещают fullscreen/extract IME; диалоги используют adjustResize, описание помещено в ScrollView.
- Инструментация прокручивает к невидимому элементу до нажатия, по-прежнему требует visible/enabled и принятый ACTION_CLICK.
- Визуальный сценарий теперь требует Arimo, видимого списка/нижней кнопки, реальной IME, полностью видимых Save/Cancel и инжектирует настоящее касание Cancel.

Android-результаты и просмотр исправленных PNG приведены ниже.
Точное расположение/состав согласованных иконок менеджера и полная визуальная
равноценность остаются непринятыми без эталонного сравнения. requirements.json и
release_gate.py не изменяются. Данные только синтетические, подпись одноразовая.

## Промежуточный прогон 41075162927 — не принят

Commit 2f6d736. API35 прошёл прежние 25 сценариев, но новая визуальная регрессия
показала: окно клавиатуры занимает y=106..296, приложению остаётся y=24..106
(82 px), у поля высота 0, кнопки выходят за нижнюю границу. PNG действительно
показывает только заголовок диалога над клавиатурой. Наличие кнопок в дереве
само по себе доступность не доказывает. На landscape-main список и нижняя кнопка
уже появились, но навигация была частично обрезана краем прокручиваемой шапки.

API23 выявил регрессию раннего получения DecorView диалога:
`requestFeature() must be called before adding content`. Шрифт диалога теперь
применяется после show; существующие OnShow-обработчики валидации сохранены.
Сборщик поворота также исправлен: текущая Activity определяется по контексту
её настоящего окна, размеры и Configuration читаются на UI-потоке.

Для короткого landscape+IME окна добавлен компактный режим: временно скрывается
стандартный заголовок, убираются лишние вертикальные отступы/фоновые inset,
сохраняются нативные 48dp кнопки и строка ввода; описание можно прокручивать.
При скрытии IME восстанавливаются исходные ширина, фон, заголовок, padding и minLines.
Навигационные кнопки вынесены из прокручиваемой шапки. Сценарий дополнительно
требует видимой строки ввода и полной видимости навигации, проверяет возврат
обычного диалога и сохранность незаписанного имени после скрытия клавиатуры.
Android-подтверждение этих исправлений требуется новым прогоном.

Декодер для сохранённого job-лога:
`python3 ci/extract_visual_evidence.py --log /path/job.log --out /path/fresh-evidence`.
Он не заменяет просмотр PNG или проверку статуса job; существующие файлы сохраняются.
