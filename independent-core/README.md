# Рабочая карта — незавершённая полная замена 26.1

**Установочного выпуска замены нет.** Версия 26.1 остаётся эталоном. Прежняя отдельная v27 не сохраняла весь её интерфейс и функции и не принимается как замена.

Цель — самостоятельная реализация всей доступной функциональности и того же внешнего вида, с согласованными исключениями геолокации, навигации по положению, оповещений о сближении, телеметрии и скрытой передачи данных. Частичная реализация не считается выполнением этой цели.

Последние этапы: собственный главный экран/каталог, форматы координат и ручной переход, редактор частей геометрии и внутренних контуров, локальные черновики, операции с отдельными вершинами, редактирование вершин на карте, менеджер папок с массовыми операциями и копирование с внутренним буфером выбора, поиск/фильтры/сортировка и массовая видимость менеджера, поиск по описаниям и собственным датам KML (28 октября), редактор описаний и проверенная запись Unicode XML (29 октября). Это ещё не весь интерфейс и не все возможности эталона. Реальные проверки и ограничения — `PARITY_PROGRESS.md`, `COORDINATES.md`, `GEOMETRY.md`, `MAP_VERTEX_EDITOR.md`, `OBJECT_MANAGER.md`, `OBJECT_CLIPBOARD.md`, `OBJECT_LISTING.md`, `OBJECT_VISIBILITY.md`, `OBJECT_DESCRIPTION_SEARCH.md`, `OBJECT_DATE_SEARCH.md`. План изолированного запуска Android — `ci/README.md`; workflow опубликован; актуальная диагностика CI и облачной задачи — `CODEX_NEXT.md`. Исторические локальные проверки описаны ниже.

Настоящие жесты, восстановление и все прежние сценарии проверены на одном APK. Журналы — `security/object-context-menu-qa-2026-10-29/`. Полный интерфейс и замена 26.1 ещё не приняты; физический телефон и Android15/16 не проверены. Установочного выпуска этой замены нет.

## Приёмка полной замены

`migration/requirements.json` содержит 23 крупных обязательных блока и контрольную сумму эталонного APK. Это верхний уровень требований, не исчерпывающий список каждого действия. `reference-ui-strings.json`, `reference-ui-usage.json`, `reference-feature-candidates.json` — указатели для подробной проверки меню и форматов. Наличие строки или записи в старой истории изменений не доказывает доступность функции; требуется подтверждение через эталон.

Финальное обновление должно использовать идентификатор и сертификат 26.1, больший versionCode и проверенный перенос прежних объектов, вложений, настроек и кеша. Текущий `org.rabochaya.karta` предназначен для изолированной разработки. Основную программу и её данные удалять нельзя.

## Текущий участок переноса

В самостоятельном коде добавлен отдельный групповой каталог онлайн-карт: 7 групп, 54 источника и 3 набора; исходные типовые изображения карточек, сведения о кеше, сохранение раскрытия групп, фильтр сохранённых карт, выбор карты, переходы к загрузке и экспорту, подтверждение очистки общих слоёв. Просмотр каталога не должен делать сетевых запросов или создавать пустые базы кеша; для этого добавлен инструментальный сценарий `catalogscreen`.

Это **не подтверждение полного совпадения интерфейса или всей программы**. Статус текущих проверок — `PARITY_PROGRESS.md`. Главный экран, остальные меню, полная поддержка форматов, DEM, управление слоями и миграция данных остаются незавершёнными.

## Сборка

Нужны Java с запуском исходников, android.jar API23, R8/D8, aapt2 и apktool. Старый исходный APK и decoded-v21 для сборки не нужны.

```
python3 owned-projects/build_additions.py --android-jar /path/android.jar --r8 /path/r8.jar --apktool /path/apktool.jar --aapt2 /path/aapt2
python3 owned-projects/build_standalone.py --android-jar /path/android.jar --apktool /path/apktool.jar --aapt2 /path/aapt2 --output /path/development-only.apk
```

Первая команда удаляет прежние сгенерированные классы соответствующих Java-модулей, затем накладывает новые. Полные собственные smali KML/SQLite/менеджера сохраняются; ABI-заглушки в APK не включаются. Вторая команда проверяет замыкание ссылок на собственные классы и собирает только самостоятельные классы, разрешённый манифест, иконку, локальные изображения карточек/кнопок, обзорную карту и Arimo.

`--release` дополнительно запускает `security/release_gate.py`. Пока требования не приняты и идентификатор установки не готов для безопасного обновления 26.1, команда завершается до создания APK. Обычная сборка — только для внутренней проверки, не доказательство готовности замены.

Ключи, пароли, тестовые подписанные APK и исходный APK 26.1 в архив не входят. Исторические результаты v27 сохранены отдельно и не подтверждают текущую доработку.
