# Черновики поиска и дат KML

На исходном 9e72294 CI 41136878460 подтвердил потерю обеих форм после реального
destroyed/recreate на API23 и API35. На API35 нативные кнопки также обрезались
портретной IME. Восемь исходных PNG проверены по SHA256 и просмотрены;
security/manager-forms-qa-2026-10-31/baseline.json содержит job IDs.
Первый API35 job с системным Launcher ANR не использован как доказательство.

ObjectFormDraft сохраняет raw текст, UTF16-выделение, focus, спиннеры, флажки и
сообщение ошибки в Bundle. Восстановление допускается только для того же project;
совпадение XML другого проекта не позволяет перенести черновик. Модель ограничена
по размеру и не разбирает даты, не пишет настройки, KML или вложения.
Применение и сброс остаются явными действиями; Cancel закрывает только черновик.

Три исходные нативные кнопки со стилями и обработчиками перенесены в закреплённую
строку под прокручиваемой формой, с целями не меньше 48dp. Arimo сохранён.
Дата проверяется только по Apply; невалидный ввод и ошибка переживают recreate.

Локально: JVM 20 наборов / 81 088 утверждений, 12 host-тестов, QA-сборка 411
собственных классов; build_result SHA256 совпадает с Java-исходниками. minSdk23,
INTERNET — единственное разрешение. Android-проверка исправления пока ожидается.
Новый managerforms требует оба поворота, настоящий destroyed/recreate и IME,
второе поле даты, Apply/Cancel/Reset, чужой project с идентичным XML и неизменность
KML/вложений. Отдельные кадры переноса — только исследование следующего пробела,
не его приёмка. Полная замена 26.1 и release gate остаются незавершёнными.
