# Экспорт состава карт в MBTiles

Production-кандидат расширяет существующее действие карты «Экспорт кеша». Если
проект использует композицию, экспорт захватывает её собственный immutable snapshot:
нижние слои рисуются первыми, скрытые/нулевые пропускаются, opacity применяется ко
всему слою. Каталожные наборы используют прежние leaf-readers и их alpha. Экспорт
из экрана отдельного онлайн-источника сохраняет прежнее значение этого действия.

Онлайн-источники читаются только из существующего кеша. Локальный MBTiles проекта
и встроенная обзорная подложка читаются существующими readers. Формируется растровый
MBTiles/TMS EPSG:3857 с bounds фактически записанных тайлов; KML, координаты объектов, описания и вложения не входят в файл
или запросы. Ограничения: 20 000 выходных тайлов, 512 МиБ, без загрузки из сети.
Отсутствующие/нечитаемые тайлы не заменяются выдуманным покрытием.

`RasterExportFile` собирает File-результат в отдельном временном файле того же
каталога, проверяет SQLite signature, sync и заменяет назначение только после
успеха. Ошибка, пустой результат и отмена не удаляют прежний File-экспорт.
Это гарантия сборщика File, **не** обещание транзакционной замены произвольного
SAF-провайдера: существующий пользовательский поток ACTION_CREATE_DOCUMENT
копирует уже готовый временный MBTiles через ContentResolver. Ошибка сборки
(включая >512 МиБ) возникает до открытия назначения. Автоматическое удаление URI
при ошибке исключено: документ может уже принадлежать пользователю. Ошибка/отмена
во время копирования SAF может оставить частичный файл; UI явно сообщает об этом.

## Проверки и границы

Локальная final QA: 485 собственных классов, min23, только INTERNET, без legacy,
native/stubs/missing references; 62 source SHA совпадают. JVM29, включая 9 проверок
File replacement; host16. `CompositionExportChecks` включён в существующий
`cacheexport`, новый baseline mode не добавлен; SDK23 instrumentation компилируется.
Android runtime нового экспорта ещё не проверен; готовность не заявлена.

Проба проверяет настоящие MBTiles-пиксели (порядок/alpha/visibility), union координат,
отмену/пустой экспорт поверх прежнего файла, локальную карту, отсутствие сети,
сохранность KML/assets и явный экспорт захваченной композиции через Activity.

Полный форматный реестр эталона, DEM, произвольные CRS, все варианты сочетания zoom
и независимая географическая сверка ещё открыты. Online raster export переиспользует `CacheExport.render` с source.zoomFor,
масштабированием WebMercator и построчным EPSG:3395 reprojection. Смешанные zoom
проверяются пикселями. Если на выходной тайл приходится больше32 исходных,
экспорт явно отказывает, сохраняя предыдущий File: дорогой слой не пропускается молча.
Отсутствующий кеш остаётся прозрачным; при полностью пустом результате — отказ.
Полная независимая географическая приёмка форматов/проекций остаётся открытой.
