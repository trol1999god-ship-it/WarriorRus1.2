# Продолжение — 19 ноября 2026

## GPX 1.1 и GeoJSON — 20 ноября

База `a75e7f8`. Обработчиков GPX и GeoJSON в исходниках приложения не было.
Импорт использует прежний локальный выбор файла и сохраняет новый KML-проект
через SQLite после разбора. Экспорт доступен в меню «Ещё» проекта, до открытия
выбора файла показывает ограничения. Карты и растры сохраняют отдельные пути
импорта и экспорта. Пакет и разрешения прежние.

GPX сохраняет точки, маршруты, части треков, высоты и известные поля точек.
Область записывается сегментами замкнутого трека, приложение распознаёт область
по собственному расширению; сторонние программы могут показывать только контуры.
GeoJSON сохраняет геометрию, отверстия, идентификаторы и свойства JSON. Высоты
передаются без пересчёта между системами отсчёта. Вложения, SVG, стили KML,
папки проекта и полная совместимость сторонних расширений требуют KMZ или
отдельного обмена. Некорректную геометрию, старые CRS, DTD и разросшиеся
входные данные обработчик отклоняет до вставки в проект.

Тестовые файлы `owned-projects/tests/fixtures/navigation-exchange.gpx` и
`navigation-exchange.geojson` открылись независимыми драйверами GDAL. GPX
проверен по XSD Topografix. Руководства OsmAnd, Organic Maps и Locus Map
описывают импорт GPX; Organic Maps и Locus Map также описывают импорт GeoJSON.
На самих трёх приложениях импорт пока не испытан.

По предыдущему CI `44800211506` API 23 прошёл; API 35 упал на мгновенной
проверке описания линейки после зума. В сценарии проверяется тот же результат
с ограниченным ожиданием обновления дерева доступности.

## Перенос между проектами

В менеджере объектов команды «Копировать» и «Вырезать» сохраняют выбор
в локальный буфер. Пользователь открывает папку другого проекта и выбирает
«Вставить в эту папку». Перед записью показаны оба проекта и путь назначения.
Вложенные папки, слои KML Document, метки, цепочки StyleMap, локальные SVG
и вложения переносятся с проверкой ссылок. Вырезание сохраняет назначение и
исходный проект в одной SQLite-транзакции и только при успехе очищает буфер.
Повторное копирование использует исходный выбор. Изменившиеся снимки и внешние
зависимости KML, которые нельзя перенести целиком, блокируют запись. Настройки растровых
подложек и их кеш не входят в перенос выбранных объектов.

Предыдущий CI 44573870412 упал на `catalogscreen` и `managervisibility` на
обоих API. Тест каталога теперь прогревает кеш через просмотр и проверяет
