# Черновики редактора менеджера при пересоздании Activity

Воспроизведение: e701b1b, CI 41119007901. API23 job 124280766902 и API35
124280767023: прежние 26 сценариев прошли, managerrotation отказал на имени
и описании. Старая Activity действительно destroyed, новая имеет другой identity;
PNG после поворота показывают менеджер без диалога и выбора. Восемь PNG до/после
декодированы с проверкой SHA256 и просмотрены. XML не менялся.

Исправление сохраняет в Bundle только несохранённое UI-состояние: project,
operation, исходный token, XML-адрес, текст и границы выделения UTF-16. Поля
ограничены 100 000 символов, чтобы черновик не раздувал saved instance state;
проверка имени до 1000 и валидация описания перед Save сохранены.
SharedPreferences и KML не используются для автоматического сохранения текста.

После загрузки проекта проверяются project/token/адрес. При совпадении
восстанавливаются редактор и выбранный объект. При несовпадении токена старый
текст показан с предупреждением и выключенным Save; выбор не переносится на
другой элемент по изменившемуся позиционному адресу. Bundle другого проекта
не открывает редактор. Исходный токен черновика не заменяется свежим токеном.

Явный Save использует этот исходный токен внутри существующей SQLite-транзакции
ObjectTreeWrites. При изменении XML после восстановления транзакция отказывает;
редактор остаётся с введённым текстом. Успех закрывает редактор; ошибка показывает
сообщение. Во время явной записи повторный Save и Cancel временно недоступны.
Cancel до Save только закрывает диалог. Activity уничтожает старое окно;
ссылки на View/Activity не переносятся в новую Activity.

JVM: 28 новых проверок ObjectEditorDraft, включая чужой project, неверный адрес,
перестановку элементов, изменение XML и сохранность текста/границ выделения.
Android-сценарий проверяет имя корневой метки и описание вложенной метки,
настоящую IME и поворот туда/обратно, Cancel/Save, изменение XML до поворота
со сдвигом адреса и после восстановления, KML, вложения и отсутствие tile requests.
Новый Android CI ещё требуется; компиляция/JVM не объявляются его успехом.

Не приняты: полный lifecycle/процесс смерти, поворот во время SQL-записи,
все масштабы/устройства, редакторы фильтров/дат, весь перенос 26.1. Обычный
массовый выбор без открытого редактора пока сбрасывается при пересоздании.
