# Расширенная сверка Рабочей карты с v26.1

Владелец отклонил установленную на Fold5 сборку `7f82cae`. Положительного решения о приёмке нет. Первичный эталон идентифицирован SHA-256 `5ac3c7091cecae66942cdffee7c91ca0eb96be5eae902e85b0d6d9920643c142`. В исходной рабочей среде доступны сохранённые индексы и статические наблюдения. Файл эталона и новые снимки отказа в этой среде отсутствуют. Неизменённый эталон ранее остановился на проверке подписи.

[Индекс элементов](RECONSTRUCTION_INDEX.json) содержит 874 ресурсных идентификатора из 14 областей. Он дополняет реестр [83 позиций](PARITY_MATRIX.json).
