# Рабочая карта — самостоятельное ядро v27

Дата: 26 октября 2026 года. Пакет `org.rabochaya.karta`, versionCode 27, minSdk 23.

Этот проект собирается без исходного APK, каталогов decoded-v21, классов/ресурсов/нативных библиотек AlpineQuest. Проверка на установленном APK перечисляет все DEX-классы: только `org.rabochaya.projects`. Основная программа 26.1 (`local.private.maps.review21`) — другая линия установки: её нельзя считать заменённой без переноса недостающих функций и данных.

## Что работает в самостоятельном ядре

- Локальные проекты SQLite, KML/KMZ и менеджер папок/объектов/ресурсов; метки, маршруты, области; описание, координаты, рисунки касаниями; сохранение и восстановление.
- Несколько фото, аудио, видео у объекта, собственный просмотр; сохранение файлов с проектом и экспорт KMZ; безопасное удаление общих вложений.
- Растровые MBTiles: TMS и явно объявленный XYZ, уровни 0–23, плоские `tiles` или нормализованные физические `map/images` с индексами. Импортированные SQL-представления не исполняются: для нормализованной схемы используется собственный фиксированный JOIN.
- 54 источника, три готовых набора карт в семи группах; прозрачные слои, quadkey, EPSG:3395 Яндекса; онлайн-просмотр, отдельные дисковые кеши, офлайн-режим, скачивание/отмена/возобновление области. Наличие источника в каталоге не гарантирует доступность его сервера.
- Экспорт сохранённого кеша выбранной карты/набора в один MBTiles/TMS, EPSG:3857, PNG. Слои объединяются с альфа-каналом; Яндекс перепроецируется. Только кеш, без сетевых запросов, объектов и медиа. До 20 000 выходных тайлов и 512 МиБ; в составном наборе экспортируются только имеющиеся данные. Нет отсутствующих в кеше тайлов — нет их и в экспорте. Для внешних программ совместимость требует отдельной проверки.
- Магнитный компас по датчикам, без геолокации. Единственное разрешение — INTERNET. Пользовательские объекты и вложения не отправляются сетевому модулю. Запросы выбранных тайлов неизбежно сообщают серверу область просмотра.

## Что ещё не перенесено

DEM/высоты и прежние офлайн-форматы помимо растрового MBTiles, полный редактор карт/наборов/порядка/прозрачности слоёв, все операции/фильтры/история объектов, библиотека SVG, отдельная передача по Bluetooth, дополнительные системы координат и утверждённый полный интерфейс. Автоматического переноса данных из основной программы нет. Это технически самостоятельное ядро, но **не полная функциональная замена основной версии**. Старое приложение и его данные удалять нельзя.

Девять источников прежнего каталога имели неподтверждённые подключения в v26: Bing Terrain, Bing Transports, Humanitarian, OSM France, MapQuest Open, Hillshade и три старых слоя OpenMapSurfer. В этой работе они не удалялись и не заменялись другим продуктом; статус их серверов заново не подтверждался.

## Исходники и сборка

`owned-projects/src` — Java-модули. `independent-app/smali/org/rabochaya/projects` — полные собственные классы, включая сохранённые реализации KML/SQLite/менеджера из предыдущих этапов; `owned-projects/api-stubs` — только ABI для компиляции, в APK не включаются. `independent-app/res` — утверждённая иконка; манифест полностью самостоятельный. Каталог определён в MapCatalog.java; AQX-файлы и старый генератор для сборки не нужны.

Нужны Java с поддержкой запуска исходников, Android android.jar API23, Google R8/D8, aapt2, apktool 2.11.1. Из корня проекта:

```
python3 owned-projects/build_additions.py --android-jar /path/android.jar --r8 /path/r8.jar --apktool /path/apktool.jar --aapt2 /path/aapt2
python3 owned-projects/build_standalone.py --android-jar /path/android.jar --apktool /path/apktool.jar --aapt2 /path/aapt2 --output /path/unsigned.apk
```

Подписывать прежним ключом `org.rabochaya.karta`, а не ключом основной review21. Закрытые ключи и пароли в архив не входят. Проверено: исходный проект без старого дерева полностью компилируется, а записи итогового APK совпадают побайтно с проверенным APK до подписи. `security/standalone-build.json` проверяет отсутствие посторонних ссылок, отсутствующих собственных классов и ABI-заглушек.

## Проверка Android

Только одноразовый эмулятор Android API23, не телефон с личными данными. Сборка тестов:

```
python3 owned-projects/build_tests.py --android-jar /path/android.jar --r8 /path/r8.jar --aapt2 /path/aapt2 --output /path/tests-unsigned.apk --target-package org.rabochaya.karta
```

Тестовый APK подписывается тем же ключом. Режимы инструментации и результаты — ANDROID_TEST_V27.md. Подменяющий HTTPS-ответ код есть только в тестах, отсутствует в приложении. `live` использует настоящий сервер; `liveproxy` дополнительно задаёт ProxySelector только в тестовом процессе для сетевого пути среды. Проверка TLS не отключается. Тестовый APK не является частью поставки пользователю.
