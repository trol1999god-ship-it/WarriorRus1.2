# Проверка самостоятельной v27 — 26 октября 2026

Проверен настоящий установленный APK org.rabochaya.karta на одноразовом Android API23. Контрольная сумма установленного файла совпала с поставляемым APK; версия 27. Геолокация отсутствует. Ключ самостоятельной линии сохранён; подписи v1/v2/v3 корректны. Полнота функций основной программы не заявляется.

Итого 615 утверждений Android в 18 успешных режимах. Дополнительно 9109 JVM-утверждений. Это проверка выбранных сценариев на одном эмуляторе, не всех Android-устройств.

`independence` перечисляет классы установленного DEX и содержимое ZIP: только собственный пакет, нет старых нативных библиотек и AQX-файлов; только разрешение INTERNET. Проверка сборки контролирует замыкание ссылок на собственные классы и исключение ABI-заглушек. Исходники вынесены из смешанного дерева; чистая компиляция из отдельного проекта без decoded-v21 дала те же байты всех записей APK до подписи.

`offlineformats` испытывает явную XYZ-ориентацию, неизвестную схему, нормализованные map/images с собственным JOIN при неверном представлении tiles, обязательный индекс и z23. `cachewrites` вызывает реальные SQLite RAISE(IGNORE) на INSERT/UPDATE: ошибку нельзя считать успешным скачиванием; проверены повтор и открытие заново. `cacheexport` проверяет целостность SQLite, чтение результата обычным OfflineTiles, отсутствие таблиц пользовательских объектов, отсутствие сетевых запросов, отмену, сохранение исходного кеша, три слоя Esri с альфой, перепроецирование градиента Яндекса и запись через callback экрана экспорта. Последний сценарий передаёт тестовый локальный URI вместо ручного выбора в системном SAF-диалоге; все реальные варианты файловых провайдеров не испытывались.

`online`, `catalog`, `cachewrites`, `cacheexport` используют контролируемые HTTPS-ответы в тестовом процессе. Проверяются настоящие production-классы SQL, URL, изображения, Canvas и Activity. В APK приложения нет URLStreamHandlerFactory тестов, ProxySelector тестов, отключения проверки TLS или тестовых сертификатов. Все 54 источника и три набора присутствуют; ответы настоящих 54 серверов в этой работе заново не проверялись.

`launcher`, `flow`, `editor`, `reopen`, `stale`, `drawing`, `drawingreopen`, `media`, `mediareopen`, `mediadelete` проверяют создание проекта/объектов, редактирование, рисунок, перезапуск, защиту от сохранения устаревшего снимка, фото/аудио/видео, копирование общих вложений и безопасное удаление. Для видео проверен отображённый синий кадр синтетического ролика, а не только getDuration. Физическая точность магнитного компаса не проверялась эмулятором; независимая математика CompassMath прошла 19 утверждений.

## Промежуточные неудачи и границы

1. Первый offlineformats не смог создать испытательное SQL-представление с несуществующей функцией: Android проверяет функцию при CREATE VIEW. Тест заменён представлением с заведомо неверным растром; production-reader использовал собственный JOIN, итоговый режим прошёл 6 утверждений.
2. Первый cacheexport ожидал ровно две таблицы. Android добавляет android_metadata; проверка исправлена на отсутствие посторонних таблиц, итоговый режим прошёл 16 утверждений. Production-экспорт ради этого не менялся.
3. Реальный live не прошёл: UnknownHostException, EAI_NODATA для tile.openstreetmap.org. Настройка системного прокси и тестовый ProxySelector также не дали успешного выхода. Глобальная настройка прокси удалена; финальное значение null. Реальное Android-соединение с картографическим сервером с обычным TLS остаётся непроверенным. Приложение не получало DNS-подмен, отключений TLS или встроенных прокси.
4. В финальном AndroidRuntime:E нет записей об аварийном завершении приложения. Сырые журналы с FAIL сохранены в security/v27-android-session.json; они не представлены как полностью успешный прогон.

## Незавершённый перенос

Нет DEM, всех старых офлайн-форматов, полноценного редактора карт/слоёв, всех фильтров/истории объектов, SVG-библиотеки, отдельного Bluetooth-интерфейса, дополнительных координатных систем и полного утверждённого интерфейса. Данные основной review21 автоматически не переносятся. Самостоятельный APK устанавливается отдельно и не заменяет основную программу без потерь функций.
