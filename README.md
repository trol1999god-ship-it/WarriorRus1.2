# Рабочая карта

Android-редактор карт, меток и папок. Текущая разработка интерфейса находится в `fix/approved-app-branding`, PR #13. Не объединять с `main` без подтверждения пользователя.

## Интерфейс

Карта занимает экран. В центре — одна красная точка фокуса. Слева сверху расположена сворачиваемая панель координат центра карты. Слева снизу — «Меню», «Объекты», «Слои», «Карты» с векторными значками. При сворачивании остаются доступные для нажатия иконки. Состояние обеих панелей сохраняется между запусками. Меню открывает плитки на тёмной панели. Справа расположены возврат ориентации на север, слои, действия в центре карты и масштабирование.

«Объекты» сразу открывают тёмный проводник локальных точек и папок: поиск по всем папкам, фильтры «Все», «Метки», «Папки», выделение, операции и создание объектов. На широком экране доступно дерево папок, в альбомной ориентации фильтры размещены в строке заголовка. «Слои» открывают только картографические слои: сейчас доступен один слой OpenStreetMap с переключателем видимости и непрозрачностью. Метки остаются видимыми при скрытии подложки. Порядок нескольких карт будет добавлен вместе с поддержкой нескольких подложек.

Название приложения — «Рабочая карта». Все стандартные, круглые и адаптивные значки используют утверждённый набор `Rabochaya-Karta-approved-icons.zip`. applicationId сохранён: `ru.warriorrus.app`.

## Реализовано и ограничения

Работают карта OpenStreetMap, использование ранее загруженных тайлов, создание и редактирование точек, подписи, папки, множественное выделение, копирование/перенос/удаление, значки SVG, локальная SQLite и восстановление объектов при повторном запуске. Длительное нажатие карты открывает меню создания метки и копирования координат.

Это промежуточный этап. До завершения требований остаются: выбор основной и дополнительной систем координат (сейчас отображается WGS84, MGRS и высота не рассчитываются), другие картографические источники, офлайн-атласы и загрузка области, маршруты/области/треки, вложения, KML/KMZ и Bluetooth. Часть диалогов ещё требует приведения к утверждённому макету. Проверка на физическом Android-устройстве не выполнена.

## Приватность

minSdk 23. Разрешений геолокации, GPS, аналитики, облачной синхронизации и выгрузки пользовательских объектов нет. SQLite и значки хранятся на устройстве, резервное копирование Android отключено. Интернет используется только для запросов картографических тайлов; пользовательские объекты в запросы не включаются. Bluetooth будет разрешён только по явному действию пользователя.

## Сборка

JDK 17, Gradle 8.9, Android SDK 35:

```sh
gradle testDebugUnitTest lintDebug assembleDebug
```

GitHub Actions: **Build Рабочая карта APK**. APK доступен в артефакте **Rabochaya-karta-debug-apk**, результаты тестов, Lint и изображения интерфейса — в **Rabochaya-karta-test-reports**. Для скачивания артефактов GitHub требуется авторизация. Устаревшие APK удалены из `downloads`, чтобы не устанавливать старый интерфейс по прежним ссылкам.

Локально выдаваемые APK следует подписывать сохранённым приватным ключом версии 6. Режим онлайн/офлайн сохраняется между запусками. Ключ нельзя добавлять в публичный репозиторий. Отладочная подпись GitHub Actions может отличаться, поэтому исходный артефакт Actions не гарантирует обновление поверх ранее выданного APK.
