# Warrior rus — локальный тактический картографический редактор

Android-проект для редактирования объектов на карте без GPS и без определения текущего местоположения пользователя.

## Реализовано в текущем прототипе

- Онлайн-карта OpenStreetMap через osmdroid, панорамирование и масштабирование.
- Создание точки долгим нажатием на карту или вводом координат вручную.
- Название, описание и папка/группа для точки.
- Локальный список точек, переход к точке и удаление.
- Прикрепление фото, видео и аудио с копированием выбранного файла в приватную папку приложения.
- Шифрование базы объектов и прикреплённых медиа AES-GCM; ключ хранится в Android Keystore.
- Одноразовая миграция точек из старого SharedPreferences-хранилища в зашифрованное.
- Импорт GPX waypoint (`<wpt>`) и ручной экспорт точек в GPX через системный выбор файла.
- Нет разрешений GPS/геолокации; `allowBackup=false`.

## Обязательные правила приватности

- Пользовательские точки и вложения хранятся в приватной директории приложения; точки и медиа шифруются на устройстве.
- В сетевые запросы не добавляются точки, маршруты, треки, заметки или вложения. Приложение не содержит собственного сервера, облачной синхронизации или аналитического SDK.
- Интернет нужен только для загрузки картографических тайлов. Поставщик тайлов всё равно может видеть IP-адрес и область карты, запрошенную устройством. Для работы без сетевых запросов следует отключить интернет на устройстве; полноценный менеджер автономных карт пока не реализован.
- Экспорт GPX запускается пользователем вручную через системный диалог сохранения. После экспорта файл находится вне приложения и его дальнейшая приватность зависит от выбранного места сохранения и последующих действий пользователя.
- Прикреплённый медиафайл копируется внутрь приложения и шифруется; исходный файл, из которого сделана копия, не изменяется и может по-прежнему находиться в другом месте (например, в облачной папке пользователя).
- Удаление приложения или очистка его данных удаляет локальную базу и ключ шифрования; экспортируйте нужные данные вручную, если хотите сохранить копию.

## Пока не реализовано

- Редактор маршрутов, треков, линий и полигонов.
- Bluetooth-передача объектов.
- Поддержка KML/KMZ, GeoJSON, MBTiles, GeoTIFF, OziExplorer и других офлайн-атласов.
- Менеджер загрузки, ограничения размера и очистки кэша тайлов.
- Настраиваемые SVG-иконки, стили слоёв и просмотр/воспроизведение вложенных медиа из интерфейса.
- Полная автоматизированная проверка безопасности и сборка APK в этой среде.

## Сборка

Откройте папку `WarriorRus` в Android Studio и выполните Gradle Sync, затем соберите `app` → `assembleDebug`. В текущей среде сборка APK не подтверждена: Gradle/Android SDK не были доступны для запуска сборки.


## Map layers in this revision
- OpenStreetMap (existing)
- Esri World Imagery and Esri World Topographic Map (online, subject to provider terms)
- Custom HTTPS XYZ template with `{z}`, `{x}`, `{y}` (online; user must have permission)
- Google Maps, Yandex, Soviet topo maps, and Maxar/Vantor are **not** bundled or integrated. Their SDKs, licensing, georeferenced map files, or authorized imagery access must be handled separately.
- This revision does not implement MBTiles, GeoTIFF, WMS/WMTS, or a provider-specific offline downloader. Do not assume tile cache rights from technical cache availability.
- Private points and attachments are not inserted into map requests. Online providers can still observe tile requests (viewport, IP).
- Build has not been verified on a real Android SDK in this environment.
