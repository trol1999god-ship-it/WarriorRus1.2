# Рабочая карта

Версия 22: интерактивные профили высоты, скорости и уклона в редакторе и карточке объекта; таблица статистики и сохранение выбранных осей при повороте. Изменения и результаты проверок — [development-v22.md](docs/development-v22.md). Полное соответствие AlpineQuest пока не достигнуто.

Android-редактор карт, меток и папок. Текущая разработка интерфейса находится в `fix/approved-app-branding`, PR #13. Не объединять с `main` без подтверждения пользователя.

## Интерфейс

Карта занимает экран. В центре — красная точка фокуса. Слева сверху — компактная сворачиваемая панель координат, справа — управление картой. Нижняя постоянная панель содержит четыре значка: «Меню», «Карты и слои», «Метки», «Ориентация». Меню разделов переводятся на исходную структуру AlpineQuest 2.4.0d с заменой серо-белой палитры на сине-голубую. Старое плиточное главное меню удалено. Системные области Android исключены из области управления.

«Метки» открывают проводник, отображаемые объекты, создание и поиск; для файлов с временными отметками появляется «Контроль времени». Панель позволяет перематывать и воспроизводить треки, ограничивать интервал и показывать положение по времени файла. Исходные объекты не изменяются. Состояние сохраняется при повороте экрана; воспроизведение при уходе из приложения приостанавливается.

Название приложения — «Рабочая карта». Все стандартные, круглые и адаптивные значки используют утверждённый набор `Rabochaya-Karta-approved-icons.zip`. applicationId сохранён: `ru.warriorrus.app`.

## Реализовано и ограничения

Работают карта OpenStreetMap, локальный кэш и офлайн-режим, точки с описаниями, папки, множественное выделение, копирование/перенос/удаление, SVG, SQLite, ручные маршруты/линии/области и редактор вершин. Выбор координат: WGS84 DD/DM/DMS, UTM, MGRS, СК-42, Пулково-1995, Меркатор и код из встроенного каталога EPSG; два формата одновременно. Добавлены варианты единиц расстояния/площади/азимута/уклона/давления. Настраиваются подписи, размер значков, толщина линий, удержание экрана.

Добавлен локальный импорт/экспорт KML, KMZ и GPX. GPX сохраняет сегменты, высоты и время треков; для полигонов необходимо выбрать KML/KMZ. Импорт добавляет данные без замены существующих и отменяется одной операцией. Bluetooth вызывается только по явному действию, через системный Bluetooth-компонент; произвольного интернет-обмена нет.

Полная функциональная аналогия AlpineQuest Pro **ещё не достигнута**. Точная матрица поддержанного и отсутствующего находится в [docs/alpinequest-parity.md](docs/alpinequest-parity.md). KMZ переносит локальные вложения и PNG-значки, а собственные метаданные позволяют обратный импорт SVG. Сторонние KML/KMZ поддерживаются частично; не все их стили и расширения сохраняются. На физическом устройстве новый файловый обмен пока не проверен.

## Приватность

minSdk 23. Разрешений геолокации, GPS, аналитики, облачной синхронизации и выгрузки пользовательских объектов нет. SQLite и значки хранятся на устройстве, резервное копирование Android отключено. Интернет используется только для запросов картографических тайлов; пользовательские объекты в запросы не включаются. Bluetooth будет разрешён только по явному действию пользователя.

## Сборка

JDK 17, Gradle 8.9, Android SDK 35:

```sh
gradle testDebugUnitTest lintDebug assembleDebug
```

GitHub Actions: **Build Рабочая карта APK**. APK доступен в артефакте **Rabochaya-karta-debug-apk**, результаты тестов, Lint и изображения интерфейса — в **Rabochaya-karta-test-reports**. Для скачивания артефактов GitHub требуется авторизация. Устаревшие APK удалены из `downloads`, чтобы не устанавливать старый интерфейс по прежним ссылкам.

Локально выдаваемые APK следует подписывать сохранённым приватным ключом версии 6. Режим онлайн/офлайн сохраняется между запусками. Ключ нельзя добавлять в публичный репозиторий. Отладочная подпись GitHub Actions может отличаться, поэтому исходный артефакт Actions не гарантирует обновление поверх ранее выданного APK.
