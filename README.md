# Warrior rus 2.0 — этап 1

Самостоятельный Android-картографический редактор. Спецификация: [WARRIOR_RUS_SPEC.md](WARRIOR_RUS_SPEC.md). Это первый рабочий этап, а не завершённая реализация спецификации.

## Архитектура

* `data/ObjectStore`: SQLite, транзакционные операции, идентичность объектов, дерево папок, локальная одношаговая отмена.
* `explorer/ExplorerController`: навигация, поиск, сортировка, выделение и буфер объектов.
* `map/MapWorkspace`: HTTPS OpenStreetMap, карта и отражение текущих объектов/слоёв.
* `MainActivity`: сенсорная рабочая область с Explorer; на широком экране карта и Explorer расположены рядом.

Предыдущая реализация заменена. Новая рабочая база `warrior2.db` независима от прежних данных и файлов обмена. Автоматическая миграция прежнего зашифрованного хранилища не выполняется. SQLite находится в приватном каталоге приложения; дополнительное шифрование базы на этом этапе отсутствует. Автоматическое резервное копирование Android отключено.

## Работает

* Карта: панорамирование, масштабирование двумя пальцами, точки с подписями, переход к объекту, добавление длительным нажатием и вводом координат.
* Переключение сетевой загрузки тайлов / использования имеющегося кэша. Кэш не является гарантированным офлайн-атласом.
* SQLite: точки и папки со стабильными ID, координатами, цветом, видимостью, порядком и прозрачностью; сохранение между запусками.
* Explorer: светлый интерфейс с округлёнными строками, дерево папок, хлебные крошки с переходом к любой родительской папке, поиск по всем папкам, сортировка по имени / порядку слоёв.
* Создание и переименование папок, редактирование точек, множественное выделение, копирование дерева, вырезание и вставка, перенос перетаскиванием за ручку ↕ в папку или дерево.
* Контекстное меню длительным нажатием, удаление с подтверждением, отмена последней изменяющей операции. Отмена и буфер действуют только в текущем сеансе.
* Видимость и прозрачность папок наследуются вложенными точками. Групповые изменения стиля выбранных объектов, изменение порядка слоя через «Выше/Ниже». Все изменения перечитываются картой сразу.
* Валидация координат, запрет переноса папки в себя или потомка, транзакционные операции с деревьями.

## Следующие этапы

Маршруты, треки, области и рисунки; вложения и их просмотр; SVG-редактор; импорт/экспорт GPX/KML/KMZ; проверка совместимости AlpineQuest; Bluetooth; офлайн-атласы и выбор провайдеров; менеджер кэша; независимые две панели Explorer; долговременная многошаговая история отмены; шифрование рабочей базы. В текущем этапе эти функции не представлены демонстрационными кнопками.

Нет GPS/геолокации, аналитики, фоновой синхронизации и передачи пользовательских объектов. Онлайн-провайдер получает запросы тайлов (область карты и IP), но не содержимое базы.

## Сборка и проверки

Минимальная версия Android: 6 (API 23); целевая: Android 15 (API 35).

JDK 17, Gradle 8.9, Android Platform 35, Build Tools 35.0.0 (AGP также выбирает 34.0.0).

```sh
gradle testDebugUnitTest assembleDebug
```

Тесты Robolectric выполняют реальные SQLite-операции (переоткрытие базы, копирование дерева, циклы, удаление/отмена, наследование стилей, буфер, поиск и сортировка) и проверяют создание папки через интерфейс и обновление настоящих маркеров osmdroid. Проверка на физическом Android-устройстве требуется отдельно.

GitHub Actions: **Build Warrior rus APK** → выбрать успешный запуск → **Artifacts → Warrior-rus-debug-apk** → распаковать ZIP. APK: `app/build/outputs/apk/debug/app-debug.apk`. Для скачивания артефакта необходимо войти в GitHub.

Готовая debug-сборка этапа: [Скачать APK](https://github.com/trol1999god-ship-it/WarriorRus1.2/raw/refs/heads/main/downloads/Warrior-rus-2.0-stage1-debug.apk). Это сборка для проверки, подписанная debug-ключом.
