# Перенос карт: эталон v20–v24

## Решение
Эталон пользовательского поведения и оформления: утверждённая линейка APK v20–v24, приоритет v24. Не задерживать разработку сравнением с v25. При отсутствии исходного APK не выдавать перечень карт за извлечённый из эталона.

## Неизменяемые требования
- Сохранить утверждённые внешний вид, значки, жесты, слои, прозрачность, порядок и переключение карт.
- Ни GPS, ни геолокационных разрешений, ни телеметрии, ни передачи объектов и вложений.
- Использовать собственную реализацию на открытых библиотеках, без закрытого кода и ресурсов AlpineQuest.
- Сохранять пользовательские данные локально; сетевые запросы могут раскрывать серверу запрошенные тайлы и IP, но не объекты.

## Источники для проверки и подключения
- OpenStreetMap: базовый источник уже в проекте; соблюсти правила публичного tile-сервера, не использовать для массового скачивания.
- Esri: спутниковые изображения, Community Maps, прозрачные подписи/дороги; уточнить доступные официальные сервисы, лицензии и условия кэширования.
- Яндекс: картографические и спутниковые слои, только через разрешённые API и условия использования.
- Google: варианты карт и спутника, только через разрешённые SDK/API, без обхода ограничений на скачивание и кэш.
- Советские топографические карты: определить правомерный источник, систему координат, проекцию и формат тайлов/офлайн-файлов.
- Maxar: только при наличии разрешённого доступа к актуальным снимкам; не обещать публичный источник без проверки.
- DEM/высоты: отдельная проверка датумов, сетки, привязки, кэша и корректности значений.
- Пользовательские офлайн-карты: импорт локальных файлов, управление слоями, экспорт выбранной области только там, где это разрешено.

## Критерии готовности
1. Реестр источников подключён к карте, выбор источника доступен в утверждённом интерфейсе.
2. Каждый утверждённый источник проверен на реальном устройстве и на соответствие условиям использования; недоступные источники отмечены, не подменены молча.
3. Прозрачность, порядок, включение/выключение и комбинирование слоёв проверены.
4. Офлайн-файлы открываются и повторно подключаются после перезапуска; сетевой кэш не выдаётся за гарантированный офлайн-атлас.
5. Координаты и DEM проверены на контрольных точках.
6. Успешная сборка, автоматические тесты и ручная проверка APK на Android.

## Текущий статус
Ветка feature/map-source-foundation содержит реестр источников и начальное подключение к osmdroid. Переключатель в UI, все утверждённые провайдеры, офлайн-атласы и проверки ещё не завершены. Эталонные APK не анализировались в этой ветке.
