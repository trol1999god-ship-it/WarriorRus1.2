# Рабочая карта: инструкции Codex

Актуальная самостоятельная реализация находится в `independent-core/`.
Остальной код репозитория — прежний проект; не подменять им текущее ядро.
Начинать с `independent-core/CODEX_NEXT.md`, README.md и migration/requirements.json.

## Обязательные требования

- Название «Рабочая карта», minSdk 23, утверждённые иконка и сине-голубой интерфейс, Arimo.
- Полная самостоятельная реализация согласованных функций эталона. Частичные модули не означают готовность всей программы.
- Никаких GPS, разрешений геолокации, телеметрии, авторизации, облачной синхронизации, онлайн-маркеров, отправки ошибок и оповещений о сближении. Компас сохранить.
- Объекты, координаты, названия, описания и вложения хранятся локально. Не включать их в запросы тайлов. Интернет нужен для выбранных пользователем карт и кеша; не превращать приложение в исключительно офлайн-продукт.
- Bluetooth и экспорт — только по явному действию пользователя. Сохранить совместимость KML/KMZ и связанные вложения.
- Не публиковать ключи подписи, пароли, токены, личные файлы или данные устройств. Использовать только одноразовые тестовые ключи в QA.
- Не удалять данные/ветки, не сливать PR автоматически. Работать в одной текущей ветке задачи и сохранять результат коммитом/PR.
- Не ослаблять release_gate.py и не помечать требования accepted без фактической приёмки. Пользовательский APK должен безопасно обновлять основное приложение с проверенной миграцией и сертификатом; тестовая сборка этого не доказывает.

## Проверки и продолжение

Рабочий каталог для команд: `independent-core`.
Быстрая проверка: `python3 owned-projects/verify_jvm.py` (Java 17, Python 3).
Настройка Android: `bash ci/setup_codex.sh`.
Сборка QA: `python3 ci/build_android_qa.py --sdk "$ANDROID_HOME" --tools /tmp/rk-tools --out "$(mktemp -d /tmp/rk-qa.XXXXXX)"`.
Android-сценарии запускает `.github/workflows/independent-core-qa.yml`; установка на личный телефон в этом workflow запрещена.
Результаты компиляции, JVM, эмулятора, визуальной проверки и телефона указывать отдельно. Ошибка среды не считается успешным тестом.
По окончании задачи обновить CODEX_NEXT.md: изменённое поведение, команды и фактические результаты, незавершённые пункты. Нельзя обещать работу после завершения задачи без подтверждённого нового запуска.
