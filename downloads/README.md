# Сборки «Рабочей карты»

Устаревшие APK удалены из исходного дерева. Используйте артефакт `Rabochaya-karta-debug-apk` успешной сборки нужного коммита в GitHub Actions. Проверяйте ветку и коммит: `main` пока не содержит последний интерфейс из PR #13.

Для установки обновления требуется та же подпись, что и у установленного APK. Готовый файл для пользователя подписывается отдельно сохранённым ключом версии 6.
