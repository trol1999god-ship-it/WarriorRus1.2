# Соответствие AlpineQuest Pro

Цель — воспроизвести структуру кнопок, вкладок, меню, последовательность действий и настройки AlpineQuest Pro с собственным оформлением Windows 11. Сходный набор возможностей не считается полным соответствием. Текущая версия — промежуточная; 100% соответствие не достигнуто.

Основные источники: [руководство 2.x](https://alpinequest.net/en/help/v2), [карты и слои](https://alpinequest.net/en/help/v2/maps), [метки](https://alpinequest.net/en/help/v2/placemarks), [ориентация](https://alpinequest.net/en/help/v2/orientation), [измерения](https://alpinequest.net/en/help/v2/placemarks/measure), [цель](https://alpinequest.net/en/help/v2/placemarks/target). Документация описывает поведение, но не подтверждает точное соответствие каждому экрану текущей платной версии. Исходный код и ресурсы AlpineQuest в проект не включены.

## Установленные исключения

Полностью исключены геолокация/GPS/GNSS, запись трека с датчиков положения, слежение за перемещением, геозоны и предупреждения приближения по текущему местоположению. Нет онлайн-поиска или маршрутизации с отправкой пользовательских координат, аналитики, облачной синхронизации и загрузки пользовательских объектов/вложений на серверы. Получение картографических тайлов разрешено. Bluetooth вызывается только пользователем. Компас работает только с датчиками ориентации и не определяет местоположение.

## Органы управления

| У оригинала | Реализация | Расхождения |
| --- | --- | --- |
| Главное меню | Нижняя первая кнопка «Меню», раздел настроек открывается напрямую | Настраиваемые ярлыки и все команды оригинала ещё отсутствуют |
| Карты и слои | Вторая кнопка: доступные карты, отображаемые карты, сохранение области | Избранные наборы, покрытие кэша, цветокоррекция и другие опции пока отсутствуют |
| Метки | Третья кнопка: проводник, отображаемые метки, создание, поиск, опции | Контроллер времени и часть дополнительных опций отсутствуют |
| Позиционирование | Исключено полностью | По требованию пользователя |
| Ориентация | Четвёртая кнопка: компас, выключатель, поворот карты, компас на карте, информация об азимуте | Нет истинного севера/магнитного склонения и всех режимов оригинального компаса |
| Длительное нажатие | Карты → каталог; метки → проводник; ориентация → включение компаса; меню → настройки | Все жесты и настраиваемые действия оригинала ещё не воспроизведены |
| Центр карты | Красная точка, контекстные команды, цель и инструменты | Состав/группировка контекстного меню и привязка цели к участку трека ещё отличаются |

## Функции

| Раздел | Реализовано | Остаётся |
| --- | --- | --- |
| Панели | Собственное оформление Windows 11, компактные значки, безопасные отступы системной навигации | Сверка каждого диалога, сочетаний жестов и состояний с конкретной версией оригинала |
| Координаты | Основные и дополнительные WGS84 DD/DM/DMS, UTM, MGRS, локальный поиск | Другие датумы, СК-42, пользовательские CRS и дополнительные единицы |
| Объекты | Точки, наборы, папки, маршруты, линии, области с внутренними контурами, импортированные треки | Разделение линий, временная шкала, все виды динамической окраски и стилей |
| Редактор | Добавление/правка/удаление/перестановка вершин, разрывы сегментов, обращение направления, имя и описание вершины | Полное поведение редакторов оригинала и точки с независимыми стилями внутри маршрута |
| Измерения и цель | Предпросмотр расстояния/азимута от центра карты, несколько участков, удаление последнего, сохранение; цель, обратный азимут, проекция точки | Указание измерений как полноценных объектов, цель вдоль трека, расчёт по рельефу, все единицы |
| Статистика | Длина, периметр, площадь, профиль высот, подъём/спуск, временные характеристики из файла | Все графики, временные фильтры, движение контроллера времени |
| Проводник | Выбор нескольких объектов, создание/копирование/перенос/удаление, поиск по имени/описанию и дате, умные выборки, шаблоны | Полное совпадение структуры и всех команд оригинального проводника |
| История | 16 изменений в SQLite, сохраняются после перезапуска, корзина и восстановление | Полный журнал действий и защищённые проекты |
| Вложения | Несколько фото/видео/аудио, локальные файлы, просмотр через явное действие, общие ссылки при копировании и безопасная очистка | Импорт всех вариантов внешних HTML-вложений из сторонних KMZ |
| Значки | SVG, палитра, папки библиотеки, ручное рисование с сохранением SVG | Все варианты редактора/стилей оригинала |
| Обмен | KML/KMZ/GPX, CSV/TSV, GeoJSON, Ozi PLT/WPT/RTE, IGC, LOC; экспорт DXF | Shapefile, все расширения KML (gx:Track, StyleMap, временные/растровые оверлеи) |
| KMZ | Стандартный doc.kml, переносимые PNG-значки и файлы вложений; собственный manifest для точного обратного импорта SVG/метаданных | Проверка чтения в AlpineQuest Pro на физическом телефоне; все чужие стили не поддержаны |
| Онлайн-карты | OSM, пользовательские HTTPS XYZ/TMS-источники, несколько карт, порядок, прозрачность | Каталоги Google/Yandex/ESRI/советских карт; доступность и условия поставщиков требуют отдельной проверки |
| Офлайн-карты | Растровые MBTiles, osmdroid SQLite/ZIP/GEMF; импорт GeoPackage для глобальной сетки EPSG:3857 | AQM, RMaps и Ozi-растры, произвольные матрицы/проекции GeoPackage, калибровка изображения |
| Сохранение области | Границы и уровни, явная фоновая задача, пауза/возобновление, квоты, MBTiles и экспорт файла | Множественные одновременные задания, формы выделения и все инструменты оригинального менеджера кэша |
| Bluetooth | Явное создание одного KMZ с объектами/значками/вложениями и запуск системного Bluetooth-компонента | Проверка передачи между двумя физическими телефонами |

Публичный сервер tile.openstreetmap.org не используется для массовой загрузки областей: это запрещено его правилами. Сохранение области доступно для добавленного пользователем источника с подтверждённым разрешением на офлайн-загрузку. Обычное отображение OSM использует локальный кэш посещённых тайлов.

## Проверки

Автоматические проверки выполняются на API 23 и 35; инструментальные сценарии — на Android 16 с жестовой и трёхкнопочной навигацией, в двух ориентациях. Проверяются повторное создание меток, сохранение геометрии, безопасные границы панелей, вложения/KMZ/история и фактическое отображение MBTiles. Результаты конкретного коммита определяются GitHub Actions; наличие теста не означает, что он уже прошёл. Полную функциональную копию нельзя объявлять готовой по одному успешному запуску сборки.
