# Соответствие функций AlpineQuest Pro

Цель: самостоятельная реализация поведения и настроек AlpineQuest Pro с утверждённым интерфейсом «Рабочей карты». Этот файл фиксирует состояние разработки, а не объявляет полную совместимость. Источники: официальное руководство https://alpinequest.net/en/help/v2, разделы placemarks, maps, settings/user-settings. Версия руководства 2.x; точное совпадение с каждой сборкой AlpineQuest не проверено.

Намеренно исключены: получение местоположения, GPS/GNSS, запись трека с датчиков, слежение за перемещением, геозоны и сигналы приближения по текущему местоположению, онлайн-поиск/прокладка маршрута с отправкой координат пользователя, аналитика и облачная синхронизация. Импорт существующих треков и ручное рисование не требуют геолокации.

| Раздел | Состояние реализации |
| --- | --- |
| Карта, масштабирование, жесты, центр, долгое нажатие | Реализовано; полного соответствия всех жестов нет |
| Постоянная нижняя панель из четырёх значков | Утверждённый собственный дизайн, намеренно отличается от оригинала |
| Основные и дополнительные координаты | WGS84 DD/DM/DMS, UTM, MGRS; расчёт локальный, выбор сохраняется |
| Датумы и проекции | Другие датумы, СК-42, пользовательские CRS пока отсутствуют |
| Метки, описания, подписи, SVG, размер значков | Реализовано |
| Папки, выбор нескольких объектов, копирование, перенос, видимость | Реализовано; отдельного типа «набор точек» пока нет |
| Проводник | Собственный утверждённый дизайн, поиск по имени и фильтры типов |
| Маршрут, линия, область | Ручное добавление вершин, изменение координат/порядка, удаление, обращение контура; сохраняются локально |
| Треки | Импорт/экспорт GPX с разрывами, высотами и временем; без GPS-записи |
| Статистика | Сферическая длина, периметр и площадь; нет временных графиков и профиля высот |
| Области с отверстиями | Импорт/экспорт KML/KMZ и отображение; интерфейс создания отверстий ещё не реализован |
| Импорт/экспорт | KML, KMZ, GPX через системный выбор локального файла; атомарный импорт и одна отмена |
| Остальные форматы | CSV/TSV, GeoJSON, SHP, IGC, PLT, WPT, LOC, DXF пока не реализованы |
| Совместимость KML/KMZ | Поддержано подмножество точек, линий и полигонов; не все стили, gx:Track, временная шкала, оверлеи и вложения |
| Bluetooth | Явное действие формирует KMZ и вызывает только системный Bluetooth-компонент; на физическом устройстве не проверено |
| Фото, видео, аудио | Пока не реализовано |
| Подложки и слои | OSM, локальный кэш, онлайн/офлайн, видимость и непрозрачность; несколько источников и порядок карт пока отсутствуют |
| Офлайн-файлы карт | MBTiles, GeoPackage, RMaps, AQM, Ozi и другие форматы пока отсутствуют |
| Загрузка области | Выбор области и уровней, фоновые задания, квоты и экспорт кэша пока отсутствуют |
| Настройки | Координаты, подписи, размер значков, толщина линий, удержание экрана, сетка; это ещё не полный набор AlpineQuest |
| История, корзина, шаблоны, умные слои | Не реализовано; есть только отмена последней операции до закрытия приложения |
| Проверки | Миграция старой базы, операции геометрии и файловый обмен покрываются автоматическими тестами; требуется проверка на телефоне |

Полную функциональную аналогию нельзя объявлять достигнутой, пока оставшиеся строки и поведение настроек не реализованы и не проверены.
