# Warrior Icons — реализация и проверка на устройстве

Открытие: кнопка **Значки** на верхней панели карты. Панель прокручивается горизонтально. Для массового назначения сначала выделите метки в Explorer, откройте Значки, выберите один SVG и нажмите **Назначить меткам**. При отсутствии выбранных меток библиотека работает как менеджер файлов.

## Реализовано

* Пользовательский каталог из `Context.getExternalMediaDirs()`: на основном общем накопителе это `/storage/emulated/0/Android/media/ru.warriorrus.app/icons`. Реальный путь показан внизу экрана. Каталог создаётся при запуске приложения.
* Папки и подпапки, хлебные крошки, сенсорные строки, флажки выделения, контекстное меню длительным нажатием, светлый интерфейс с округлёнными строками.
* Создание папки и SVG из текстового шаблона; переименование; рекурсивное копирование, вырезание/вставка, перенос по относительному пути; удаление с подтверждением. Вложенное выделение не дублирует операции. Коллизии имён и циклические переносы отвергаются до начала групповой операции; существующие файлы не перезаписываются.
* Импорт одного/нескольких SVG через Android Storage Access Framework (`ACTION_OPEN_DOCUMENT`). Выбранные документы копируются в библиотеку; постоянные разрешения на исходные URI не нужны.
* Новые файлы, скопированные компьютером в пользовательский каталог, обнаруживаются при сканировании. FileObserver наблюдает папки, а проверка изменений каждые 3 секунды в открытом приложении страхует пропущенные события. При возврате в приложение и по кнопке **Обновить** выполняется пересканирование. В фоне обработка останавливается.
* Миниатюры и крупный предпросмотр AndroidSVG. Изменение цвета означает окрашивание силуэта; исходный SVG не переписывается. Цвет сохраняется у назначенных меток и в настройках предпросмотра. Прозрачные отверстия сохраняются.
* Назначение одного SVG и цвета нескольким меткам одной SQLite-транзакцией. При копировании меток сохраняются значок и цвет. При управляемом переименовании/переносе файлов и папок обновляются ссылки в базе.
* Два встроенных SVG (pin/star) в отдельной библиотеке, доступной только для чтения. Файловые операции не могут удалить, переименовать или переместить встроенные значки.
* Удалённый/повреждённый SVG заменяется запасным маркером: ID, название, координаты и ссылка метки сохраняются. Восстановленный файл с прежним путём вновь используется. Внешнее переименование через USB не угадывается: выберите новый файл и назначьте меткам повторно.
* Миграция SQLite версии 1 → 2 сохраняет существующие метки и добавляет встроенный значок по умолчанию.

## Ограничения Android

Приложение не запрашивает `READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`, `READ_MEDIA_*` или `MANAGE_EXTERNAL_STORAGE`. Используется только принадлежащий приложению media-каталог; посторонние файлы читаются по URI, выбранному пользователем. `getExternalMediaDirs()` доступен с API 21, но помечен deprecated с API 30; доступ к своему каталогу сохраняется. Не используется запрещённый для обычного доступа путь `Android/data`.

На компьютере подключите разблокированный телефон, выберите USB **Передача файлов / MTP**, откройте внутреннюю память → `Android/media/ru.warriorrus.app/icons`, скопируйте папки и `.svg`, затем вернитесь в приложение или нажмите **Обновить**. Видимость каталога и SVG через MTP, разрешения стороннего файлового менеджера и задержки обновления зависят от версии Android, производителя, драйвера и USB-режима. Они требуют проверки на физическом устройстве. Если компьютер не показывает каталог, доступный обходной путь — скопировать SVG в Downloads и импортировать через кнопку **Импорт SVG**.

Не гарантируется сохранность каталога после удаления приложения: экспортируйте библиотеку вручную на компьютер перед удалением. Данные не передаются автоматически в интернет. Отмена Explorer не переносится между экраном карты и библиотекой: при открытии менеджера файлов прежний снимок отмены очищается, чтобы отмена старого действия не восстановила устаревшие ссылки.

## Формат и безопасность

Размер SVG ограничен 256 КиБ, количество элементов — 2000. Предпросмотр поддерживает локальную геометрию AndroidSVG, включая локальные fragment-ссылки. Скрипты, внешние изображения/ссылки, XML entities/DOCTYPE, CSS imports, внешние paint URL, foreignObject и анимация отвергаются. Это намеренное ограничение SVG, а не полная поддержка браузерного SVG. WebView и сетевой resolver не используются. Символьные ссылки, выход из корня и удаление корня запрещены. Повреждённые файлы, добавленные по USB, видны как строки с предупреждением и могут быть удалены; карте они не мешают.

## Проверки

`gradle testDebugUnitTest lintDebug assembleDebug`. Тесты проверяют файлы на настоящей временной файловой системе, реальные SQLite-транзакции и миграцию, SVG-пиксели с native graphics Robolectric, UI/SAF и manifest-разрешения в Robolectric API 23 и 35. USB/MTP, работа системного DocumentsUI конкретного телефона, реальные FileObserver-события и установка APK требуют проверки на устройстве. Производительность больших библиотек также требует оценки на телефоне. Не изменяйте одновременно те же файлы по USB и через менеджер.
